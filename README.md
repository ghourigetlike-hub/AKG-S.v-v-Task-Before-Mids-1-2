# VV Lab 209 — PSVS

## Project Overview

This project focuses on Software Verification and Validation (SV&V) for a Polar Seed Vault System.

## Objectives

* Manage and verify system requirements.
* Identify and document requirement defects.
* Maintain configuration and version control.
* Improve requirement quality through verification.

## Repository Structure

* requirements/ — System requirements
* defect-logs/ — Defect records and peer reviews
* abstractions/ — System abstractions
* models/ — Formal models
* operations/ — System operations
* constraints/ — System constraints
* proofs/ — Verification proofs
* reports/ — Summary reports and charts

## Lab Tasks

1. Orientation and Configuration Management
2. Defect Taxonomy and Verification Logging
